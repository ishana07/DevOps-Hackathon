📐 SLA & Downtime Calculation Methodology

1. Availability Percentage Formula

$$\text{Availability } (\%) = \left(\frac{\text{Successful Checks (HTTP 2xx)}}{\text{Total Checks}}\right) \times 100$$

A check is strictly classified as UP if and only if the HTTP response status code is within the 200–299 range. Any 3xx, 4xx, 5xx, network drop, timeout, or DNS failure is classified as DOWN.

2. Average Response Time

$$\text{Avg Latency (ms)} = \frac{1}{N} \sum_{i=1}^{N} \text{Response Time}_i \quad \text{(for all valid responses)}$$

Calculated across all checks where a response was obtained. Connection drops and unresolvable network failures are excluded from latency averaging to prevent skew.

3. Estimated Downtime vs. Continuous Outage

$$\text{Estimated Downtime} = \text{Failed Checks Count} \times \text{Polling Interval (seconds)}$$

Important Statistical Clarification for Judges:

Interval-sampled monitoring polls at discrete intervals (e.g., every 10s). If 3 consecutive checks fail with a 10s interval, the estimated downtime is 30 seconds.

This is an interval-based estimate because outages that begin or recover between polling moments cannot be observed with sub-second continuous precision without continuous streaming or push-based APM agents.
